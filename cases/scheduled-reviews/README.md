# スケジュールによる定期レビュー

![毎週日曜に ChatGPT が GitHub の記録と会話を読んで分析し、最初に決めた指示文に沿って結果を保存し、レビュー結果を本人へ報告する流れ](cover.png)

情報の定期的な確認と振り返りを、ChatGPTのスケジュールで実行する事例。
AIが最新情報と記録を確認・分析し、人間が提案を評価して次の行動を決める。
**2026-10-31に、現行の設定と、10月25日の読書レビューとコンテキスト更新の完了記録・保存の報告を確認。成果物の独立検証と効果測定は未実施。**

| 従来 | 運用の形 |
| --- | --- |
| 確認のたびに依頼する | 指定した周期でAIが確認・分析し、結果を受け取る |

**AI：** 記録の取得、情報収集、分析、許可した範囲への保存・更新、報告。  
**人間：** 目的・周期・判断基準の設定、提案の採否、次の行動。

読書レビューは毎週日曜20:30を基準に時刻の幅を持たせて実行し、会話から長期的な差分を残すコンテキスト更新は毎週日曜22:00（日本時間）に実行する。取得や保存に失敗したときは、そのことを明示する。

週次のコンテキスト更新はChatGPTだけで行う。Claude.aiの会話からの週次更新は2026-10-30にやめた（本人の申告。関連する全体構成の記録と照合した）。

どちらの処理も、直近の実行は記録上completedで、同じ実行の報告に保存・更新したと書かれている。実行日時だけで成功とは見なさず、成果物の内容と継続効果は別に検証する。
