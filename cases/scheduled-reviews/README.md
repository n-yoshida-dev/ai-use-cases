# スケジュールによる定期レビュー

![定期レビューの課題・AI・人間・確認状況](cover.png)

定期的な情報確認・振り返りを、ChatGPTのスケジュールで実行する事例。
AIが最新情報と記録を確認・分析し、人間が提案を評価して次の行動を決める。
**既存の週次処理の有効設定と実行日時を確認。成果物と効果は未検証。**

| Before | 運用の形 |
| --- | --- |
| 確認のたびに依頼する | 指定した周期でAIが確認・分析し、結果を受け取る |

**AI：** 記録の取得、情報収集、分析、許可した範囲への保存・更新、報告。  
**人間：** 目的・周期・判断基準の設定、提案の採否、次の行動。

例として読書レビューや情報収集で利用。指示には取得失敗や保存失敗を明示する運用を含める。
実行日時は各処理の成功を保証しない。成果物確認と本人の作業時間測定を今後の検証に残す。
