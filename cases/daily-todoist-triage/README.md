# 毎朝のTodoist整理をAIへ委譲

![TodoistのInboxの未整理タスクをChatGPTが毎朝、GitHubの手順書にある基準で整理し、時間・担当のタグと優先度を付けて同じInboxへ戻す概念図](cover.png)

積み重なるタスクをChatGPTが毎朝6時（日本時間）に整理する。
**現行の設定と、2026-10-31朝の完了記録、更新後に再取得したという報告を確認。結果の独立検証と効果測定は未実施。**

**AI：** Inboxの分類、親子関係・タグ・優先度の整理、今日の候補の選定。  
**人間：** 判断基準・除外範囲・例外の決定と実作業。

2026-10-30から、予定の指示文では非公開の運用ルールの「Todoistと日次タスク整理」節を全文読んで従うように指示している。基準を二重に管理せず、読めない日は整理しない。日曜の大きな目標の見直しは今の運用に含めない。

- 編集するのはInboxだけ。ほかのプロジェクトは近い期限を確かめるだけ。繰り返しのプロジェクトとその配下は除く。
- 確定した期限と、開始の条件を分けて扱う。着手待ちのタスクは時間タグを付けずにP4にする。P1/P2にするのは着手できるものだけ。
- 今日の候補は1〜3件。更新後に再取得し、日付・親子関係・既存のタグが残っているかを確かめる。

同じ毎朝の処理で先に[メール仕分け](../daily-email-triage/)を行い、そこで登録されたタスクも整理する。
