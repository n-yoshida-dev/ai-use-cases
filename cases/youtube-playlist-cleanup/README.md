# YouTubeマイリスト整理をAIへ委譲

![課題・AI・人間・確認待ちの関係](cover.png)

増えたマイリストを手作業で確認する負担を、ChatGPT WorkのComputer Useへ委譲する事例。
AIに現状確認・分類・整理操作を任せ、人間は残す基準と整理方針を決める。
**現在は依頼・方針を記録した段階。完了結果は未確認。**

| Before | 設計したAfter |
| --- | --- |
| 人間が各リストを開いて整理する | AIが確認・整理し、人間が結果と例外を判断する |

**AI：** 棚卸し、分類、統合候補の抽出、許可範囲の操作。  
**人間：** 残す基準、統合・削除の方針、必要な例外判断。

作成・削除・統合も依頼範囲に含む。実施件数、変更前後、削減時間は未確認のため実績に含めない。
再利用できるのは「GUI上の整理作業を、判断基準と操作に分けて委譲する」設計。
