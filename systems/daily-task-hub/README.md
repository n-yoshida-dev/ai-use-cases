# 複数の入力をTodoistへ集め、毎日整理する

![メール・音声・手入力をTodoistに集め、AIが整理し本人が実行する全体図](cover.png)

メールからの自動登録、iPhoneのアクションボタンからの音声指示、アプリ・ブラウザでの手入力をTodoistへ集約する。ChatGPTが毎朝メールを仕分けてからInboxを整理し、本人は整理結果を確認して実際の作業を行う。

| 段階 | 担当と役割 |
| --- | --- |
| メールを拾う | ChatGPTの毎朝6時の処理が、最初にGmailを仕分けて要対応をInboxへ登録（2026-10-28まではClaude Codeのルーティンが7時に実行） |
| 思いつきを入れる | 本人が音声指示、アプリ、ブラウザから入力。音声の中継アプリ・内部経路は未確認 |
| 保存から買い物へ | ChatGPTのブックマーク整理で、近々買うものを買い物プロジェクトへ。初回登録を確認、週次設定済み |
| 集約する | Todoistがタスク管理の正本。主な整理対象はInbox。ブックマークからの買い物登録は別プロジェクトで、日次Inbox整理との自動連続実行は保証しない |
| 整理する | 同じ毎朝の処理の続きで、メール由来を含むInboxの分類、親子関係、時間・委譲先、優先度、実施順を整理 |
| 行動する | 本人が結果を確認して実行。タグ付けだけで別AIの作業が始まるわけではない |

繰り返しプロジェクトは棚卸しから除外。他プロジェクトの期限確認は読み取りだけ。整理の書き込みはInboxに限定する。

**図は情報の流れを示す。メール仕分けとInbox整理は、2026-10-28から同じ毎朝の処理の中で順に動く。** それ以外の入力（音声・手入力・週次の振り分け）は、入った時点で後続処理が起動する連鎖ではない。

移行前の本人説明にあったメール登録の「最大5件」は、移行後の手順書には無いため図から外した。音声経路は本人説明に基づき、設定を直接検証していない。

2026-10-21からは、整理後のTodoistを各リポジトリの作業・予定と並べて1日の時刻割りにする[横断タスクボード](../cross-task-board/)を別の全体構成として試用中。そこではClaude Codeが本人の指示を受けたときだけ、Todoistのタスクを完了・日付変更する。
