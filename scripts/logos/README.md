# サービスのロゴ

図の中でサービスを指すためのロゴ。`figkit.service()` / `figkit.logo()` が読む。

- 出どころ：[Simple Icons](https://simpleicons.org/)（v15.22.0）。SVG は CC0 1.0。ブランドの色は Simple Icons のデータに合わせた（ChatGPT は OpenAI のロゴを黒で使う）
- 各ロゴは各社の商標。この一覧ではサービスを指すためにだけ使い、ほかの用途には使わない
- PNG は SVG を 256px に描いたもの。足すときは SVG に `fill` を入れて同じ大きさで描き、ここに SVG と PNG を両方置く
- Simple Icons に無いサービスも、名前の文字だけで済ませずにロゴを探して足す（2026-11-02 本人「ロゴも調べて入れといてね」）。
  探す順：Simple Icons → Iconify の自由なライセンスの集まり（selfh.st など） → 公式のアプリアイコン・サイトのアイコン。出どころとライセンスを下の表に書く
- Simple Icons 以外から足したもの（2026-11-02）
  - amazon・raindrop：[selfh.st/icons](https://github.com/selfhst/icons)（CC BY 4.0）の SVG を 256px に描いた
  - mercari：App Store のメルカリのアプリアイコンから、白い地を除いてマークだけを切り出した（SVG なし）
  - keepa：keepa.com のサイトのアイコン（192px）を 256px にした（SVG なし）
