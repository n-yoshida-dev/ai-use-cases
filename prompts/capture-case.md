# AI活用ケースの記録

AGENTS.mdを全文読み、今回参照できる会話と実際の成果物から、再利用可能なAI活用ケースを整理してください。

1. 既存ケースを確認し、同じ事例なら更新する。保存価値がなければ理由だけ報告する。
2. 公開可能な内容だけを抽出し、本人の判断、AIの担当作業、実施状況、結果、未確認点を区別する。
3. テンプレートから短いREADMEとmeta.yamlを作る。根拠は公開可能な説明で残し、会話全文は保存しない。
4. 課題・AI・人間・結果を表すcover.pngと編集可能な元を作る。概念図は概念図と明記する。
5. トップの画像付き一覧を更新し、リンクと3ファイルの整合を検証する。
6. 変更点・確認できた成果・残る未確認点を簡潔に報告する。未実施を成功扱いしない。

この指示はケース記録用であり、元の作業の追加実行、定期タスク作成、記事投稿を指示しません。
