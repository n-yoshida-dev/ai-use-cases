# 日本語の概念図・説明図

## cover.png：一目で分かる入口（必須）

- 横1440pxのPNG。縦は中身に合わせて `figkit.save()` が切り詰める（最大900）。図に書く文字は日本語ラベルと固有名詞だけにする。段落や文章カードを並べない。
- 図の中に題名・副題・説明の帯・「実画面ではない」の注記・確認状況の文を入れない（READMEとmetaに書く）。
- サービスは `figkit.service()` のロゴで示す（ChatGPTは `openai`、Claudeは `claude`。一覧は `scripts/logos/README.md`）。ロゴが無ければ探して `scripts/logos/` に足す（探す順・出どころ・足し方は `scripts/logos/README.md`）。図を描けないときは `figure_todo` に「ロゴなし：<サービス>」と書く。
- 大きな人物・対象・画面・時計・整理先などの絵、矢印、位置関係で仕組みを伝える。
- 「誰が、何をAIへ任せ、どこで判断するか」を伝える。各ラベルは原則12字以内。説明の文は置かず、並びと矢印で読ませる。
- 未確認の結果・予定の流れは図に描かず、READMEとmetaに書く。実画面と区別する。
- 白〜薄い背景、少数の色、十分な余白。サムネイルでも絵の意味が分かること。

## flow.png：手順の流れ図（任意の2枚目）

1つの仕組みを詳しく見せるときだけ足す。cover.pngの代わりにしない（型の正本は `AGENTS.md`「見せ方と図」。例は `cases/daily-email-triage/flow.png`）。

- 上から下へ、「誰がやるか」の枠（ロゴと名前）を順に並べ、枠の中に「やること」の箱を置く。
- 分かれる所は、分かれた結果を箱の下に書く。最後に本人に届く物を置く。
- README先頭には置かず、本文の後ろの折りたたみに置く。紹介資料に載せるときは `deck` の part の項目の `flow` と `flow_alt` に書く（whole には書けない）。
- 編集元は `figure.py` でも `flow.html`（HTMLから書き出す）でもよい。どちらも同じフォルダに残す。`flow.html` から描いたら meta の `visual.explanation_source` に書く。
- 概念図と内容・実施状況が一致すること。

## そのほかの図（紹介資料用など）

`<名前>.py` → `<名前>.png` で同じフォルダに置く。書き方は `figure.py` と同じ（先頭に再生成の手順と書き出す図の名前、部品は `../../scripts` の figkit、`--font` を受け取る）。meta の `visual.extra` に `image` と `source` の組で並べる。紹介資料に載せるときは meta.yaml の `deck` の `figure` に名前を書く。

## 生成

編集元：`cases/<id>/figure.py`（全体構成は `systems/<id>/figure.py`）。絵の部品（人物・画面・封筒・時計・サービスのロゴなど）は `scripts/figkit.py` を使う。Python 3、Pillow、日本語フォントが必要（フォント本体は同梱しない）。
`python cases/<id>/figure.py --font /absolute/path/日本語フォント` で、そのケースの図だけを生成する。
フォントが違うと見た目が同じでもPNGのバイナリが変わるため、ケースを直すときは他ケースの画像を再生成しない。部品を直したときだけ全件を描き直す。
生成後はcover.png（あればflow.pngも）の欠字・はみ出し・重なりを目視確認する。

## 図を描けないとき（ChatGPT のチャットなど）

画像生成や手描きで代わりの図を作らない。meta.yaml に次の形で書き、描くのは Claude Code に任せる（決まりの正本は `AGENTS.md`「見せ方と図」）。

```yaml
figure_todo:
  - 図: cover.png
    順番: Gmail → ChatGPT → Todoist     # 左から右への鎖。並べるのは同時に入る入力だけ
    置く物: [Gmail, ChatGPT, Todoist, 本人]
    きっかけ: 毎朝6時                    # 定期実行なら書く。AI の札の真上に時計で置く（線の上には置かない）
    置き場: [判定基準]                   # 最初に 1 回決めた手順書・基準。AI の左に置き、本人から矢印を引かない
    矢印: [Gmail→ChatGPT「新着メール」, ChatGPT→Todoist「要対応タスク」, ChatGPT→本人「朝の報告」]   # ラベルは動くデータの名詞、12 字以内。本人から引くのは毎回本人が渡す物だけ
    AI の動詞: 読んで仕分け
  - 図: flow.png                       # 手順の流れ図。上から下への枠と箱
    きっかけ: 毎朝6時
    枠: [ChatGPT, 本人]                    # 上から順に「誰がやるか」
    やること: [ChatGPT「未読を読んで仕分け」（下に分かれた結果：要対応・要確認など）, ChatGPT「要対応をTodoistへ」]
    届く物: 朝の報告                        # 最後に本人に届く物
```

書いた `figure_todo` は、Claude Code がこのリポジトリを触るたびに最初に流す点検で一覧に出して拾う。
